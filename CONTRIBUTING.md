# Contributing to Chuo Connect Kenya

First off, thank you for considering contributing to Chuo Connect! It's people like you that make this platform a powerful tool for students across Kenya.

## Development Process

1. **Fork the Repository**: Create your own fork of the repository on GitHub.
2. **Create a Branch**: Create a feature or bugfix branch (`git checkout -b feature/amazing-feature`).
3. **Commit Changes**: Make your changes and commit them using [Conventional Commits](https://www.conventionalcommits.org/) formatting.
4. **Push & Open PR**: Push to your fork and submit a Pull Request against the `main` branch.

## Code Style

- We strictly use **TypeScript**.
- All components must be built using **React Server Components (RSC)** by default, using `'use client'` only where interactivity is required.
- Follow our Tailwind CSS conventions (we use utility classes directly, avoid arbitrary values where possible).

## Review Process

All pull requests will be reviewed by the core team. We may request changes or suggest improvements before merging.

Thank you for your contributions!
